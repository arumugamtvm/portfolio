About me

A bit
about me.

I'm a software engineer. I enjoy taking an empty file and turning it into something people can really use.

I build fast and keep improving. I like to ship a working version early, then make it better step by step.

I care about the things that make software good: clean, readable code, clear names, and handling errors so the next person (often me, months later) has an easy time.

I work mostly with JavaScript, TypeScript, C#, Dart, Node.js, and React. I'm always learning something new.
